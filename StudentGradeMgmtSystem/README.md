# Student Grade Management System
[Live Website](https://eshwari-m.github.io/StudentGradeMgmtSystem/)

A simple web application for managing student marks and grades.

## Features

- Add student details and marks
- Validate student name and marks
- Calculate total and average
- Assign grades from A to F
- Display student records in a table
- Delete student records
- Filter students by grade
- Check for duplicate student names
- View class summary
- Export student data as JSON
- Uses push(), map(), filter(), reduce(), and find()
- Uses try-catch for error handling

## Technologies

- HTML
- CSS
- JavaScript
- Bootstrap
